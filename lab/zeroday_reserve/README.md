# 0day reserve lab

Standalone dynamic cases for findings that are **not** in the existing 96
mining candidates.  Each case pins the real upstream source under
`upstream/`, runs a PoC against it, and records a hash-pinned `result.json`.

```
cases/<id>/
  manifest.json   upstream tag/commit, root cause file:line, preconditions, marker
  poc.py          real upstream class/function or real FastAPI router/middleware
  evidence/       marker, log, crafted artifacts
  result.json     generated by harness.py
upstream/         verbatim source snapshots (hashes in manifests)
```

Run:

```powershell
python -m lab.zeroday_reserve.harness --all
python -m lab.zeroday_reserve.harness --id vllm-rl-dev-auth-bypass
```

Current cases:

| id | component | type | proof |
|---|---|---|---|
| `vllm-rl-dev-auth-bypass` | vLLM 0.32.0 | real router + real AuthenticationMiddleware, ASGI HTTP | `/v1/ping` 401, `/pause` and `/weight_checker` 200 without token |
| `sglang-legacy-tar-weights-rce` | SGLang 0.5.22 | verbatim `_load_pt_file` + torch | legacy-tar `storages` pickle executes on `weights_only=False` fallback; **already-public CVE-2026-15976** |
| `deepspeed-autoep-unsafe-load` | DeepSpeed 0.19.8 | real vendored `autoep_universal` + torch | malicious expert shard executes in `torch.load(weights_only=False)` |
| `msswift-media-local-read` | ms-swift 4.6.0 | verbatim `SafeMediaPath` + `to_base64` | default-allow local path returns canary bytes; allowlist control refuses |

`result.json` is evidence, not a disclosure.  See `docs/0DAY-DISCLOSURE.md`.
