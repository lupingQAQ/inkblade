# AutoPenBench — 自主 vs 半自主渗透 agent 的 33 任务基准

- 分类：agent-2026 / 评测
- 来源：arXiv 2410.03225（v2 2024-10-28）
- 核验日期：2026-10-25；核验状态：verified（webfetch 200，摘要页命中）

## 来源
- https://arxiv.org/abs/2410.03225
- https://github.com/lucagioacchini/auto-pen-bench

## 核验（实际读到的）
- 33 个任务，每个是一个待攻击的脆弱系统；难度递增，含 **in-vitro 与 real-world** 场景。
- 评分：通用里程碑 + 特定里程碑，标准化比较并定位 agent 极限。
- 对比两种架构：**全自主** vs **半自主（支持人类交互）**。
- 结果：全自主 **21% SR**，简单任务 27%，真实任务只解 1 个；半自主 **64% SR**。还比较了 GPT-4o 与 OpenAI o1 对完成率的影响。

## 架构要素
- 任务=可攻击系统 + 里程碑评分，不依赖单一 flag。
- 自主度是实验变量，不是产品口号。
- 真实任务显著难于 in-vitro，暴露泛化差距。

## 对我们的启示
- 我们没有任何渗透 agent 基准（G09）；AutoPenBench 的「里程碑 + 自主度对照」可以直接作为我们升级的验收框架。
- 21% vs 64% 是「HITL 值得保留」的硬证据：我们的审批制不是落后，但需要把审批做成低摩擦的异步恢复（G03），否则人机协作成本会吃掉收益。
- 评测任务应分「mock/仿真/真集群」三档，与我们现有 lab 分层一致。
