# Sigstore samples

These files are fixtures for `tests/test_sigstore_keyless.py`. They are **not**
runtime data and must not be regenerated casually.

| File | Kind | Rule |
|---|---|---|
| `fixture-*` | generated by the in-repo fixture CA (`FixtureAuthority`) | may be regenerated, keep the trio consistent |
| `real-keyless-*` | a real cosign keyless signature (Fulcio cert + Rekor entry) for `real-keyless-cosign-checksums.txt` | artifact bytes are frozen; the Rekor entry is immutable |
| `live-rekor-*` | a real key-based cosign signature written to the public Rekor log | artifact bytes are frozen; changing one character breaks the log entry |

## Why the frozen bytes still say "trident"

`live-rekor-artifact.txt` was signed and recorded in the public Rekor log before
the project was renamed from Trident to InkBlade. A transparency-log entry commits
to the exact artifact digest: rewriting the text invalidates the inclusion proof
and the `tlog-body` check. The sample therefore keeps its original bytes and the
file name is the only thing that changed.

If you need a renamed sample, create a **new** signature (new Rekor entry) and add
it as an additional fixture - never edit a signed artifact in place.
