## 判定口径（2026-10-25 三态）

- **真实验证**：仓库内可复现实现 + 自动化测试/可重复 e2e 覆盖，且执行路径真实（真实进程/HTTP/CLI/K8s 或真实外部服务）；本地 mock 靶场不等于生产环境。

- **模拟验证**：有可复现实现与测试，但证据来自 fixture、契约仿真、emulator、离散事件仿真或单机模拟；明确标注边界，不冒充真实硬件/云账号/生产信任链。

- **仍未达成**：只有设计、脚本或公开资料对照，没有可复现的实测数据；不写成「已支持」。

## Ruling 与边界

1. **三态不是营销标签**：`真实验证` 只用于真实执行/真实外部服务；fixture、契约仿真、emulator、离散事件仿真一律 `模拟验证`，并保留「非真实硬件/账号/生产信任链」的显式说明。

2. **fixture ≠ 生产证据**：供应链 HMAC、TEE fixture、云契约仿真均不得当作硬件或生产信任链通过；本轮公共 Sigstore/TEE 样本验证也仍是「验证器真实」，不等于自有生产签发/硬件测量。

3. **规划 ≠ 执行**：`agent_planner` 与 MCP `get_chain_plan` 只输出计划；审批角色固定 lead，`execution.trigger=human`、`performed=false`；测试锁定零 actions 写行。

4. **合规映射 ≠ 认证结论**：七框架映射是多标签工程归类，未命中具体类别时使用平台面兜底条款；官方文本优先。

5. **corpus 是公开基线**：35 源均记录核验日期/方法/缺口（见 `coverage-matrix.json` 的 notes），不把厂商文档阅读等同于现场实测。

6. **效果级 ≠ 集群级**：本机真实进程/HTTP 的效果验证与 live K8s 集群验证分开陈述；QEMU TCG 下的绝对性能值不作为产品级性能结论。

7. **本轮新增边界**：Sigstore 公共 keyless 验证使用第三方真实产物（cosign v3.1.4 checksums），自有签名仍为 fixture CA；TEE 公共链真实但无硬件 quote；六云/万卡/SaaS 均为模拟/本地，不改变对应「真实环境」缺口。

## 芯片/加速器能力边界（必要性分级，2026-10-26 收紧）

本节的计数口径与 `docs/CHIP-SECURITY-SCOPE.md` 一致；**C/D 不计入“芯片渗透能力”**。

| 级别 | 能力 | 本仓库口径 | 是否计入芯片渗透能力 |
|---|---|---|---|
| A 真攻击路径 | IOMMU/SMMU 直通与 DMA；BMC/DPU/IPMI 带外接管（含 Redfish UpdateService/FirmwareInventory）；GPU 显存/MIG/MPS 跨租户残留 | 做深、做对抗用例；A2 复用已有模块，A3 有 benign marker 写读回 | **计入** |
| B 保障性审计 | GPU CC 证明链（NRAS JWKS/nonce/claims）；固件签名/安全启动/TPM/微码吊销 | 只读/检测；报告写 false trust/持久化风险，不写“攻破” | 计入“保障性检测”，不计入“攻击拿下” |
| C 前瞻/低必要性 | SPDM/PCIe DOE 细项；NVLink/IMEX 配置审计（GB200/NVL）；CXL（有面才启用） | `research-only`、默认关闭；无面即 no-surface | **不计入** |
| D 明确不做 | RTL/GDSII/DFT、功耗电磁侧信道、电压毛刺/激光、开盖探针、芯片逆向、counterfeit、Rowhammer 实操、微架构侧信道实操 | 硅片/物理实验室范围，不实现、不宣传 | **不计入** |

因此，SOTA 表中的“芯片/加速器”行只应引用 A 类真实路径与 B 类保障性检测；C 类最多写
“research-only 配置审计，默认关闭”，D 类只写“明确不做及原因”。不得把 fixture 数、
模块数或 C 类有面项写成“芯片渗透能力”。
