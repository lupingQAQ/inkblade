InkBlade v0.2.0

Authorized penetration testing for Kubernetes ML training and inference clusters. Consent pinning, technical-level gates, a backup gate for write modules and per-action auditing are enforced in code. Without a signed record the CLI and the HTTP API both refuse to run.

Start here

python -m inkblade doctor            # interpreter, write access, port, optional deps
python -m inkblade pilot --dry-run   # offline rehearsal: profile + plan, no cluster contact
python -m inkblade ui                # local console on 127.0.0.1:8765
python -m inkblade exploit --list    # weapon packs and their deployment requirement

With a cluster you are allowed to read: inkblade pilot --kubeconfig ~/.kube/config. Execution of any module needs a signed scope first — inkblade quickstart walks through it.

What it covers

286 modules, 29 chains

Recon, lateral movement, network architecture, privilege chains, core code paths, exfiltration, hybrid cloud, intelligence.

Three evidence layers

Context journal, SQLite audit tables and a per-step archive with a SHA-256 manifest. Report anchors are step hashes.

Bilingual reports

PTES-style pentest narrative plus a remediation checklist, generated from the same evidence, in Chinese and English.

Vulnerability coverage

41 verified primitives across 24 components, listed by component, class and affected version — no payloads, no target lists.

中文

InkBlade 是面向 Kubernetes 训练/推理集群的授权渗透测试平台。授权范围、技术级别、写操作备份与逐动作审计 都在代码里强制执行；没有签署记录时，CLI 与 HTTP API 都会拒绝执行。

python -m inkblade doctor            # 解释器、写权限、端口、可选依赖
python -m inkblade pilot --dry-run   # 离线演练：画像 + 计划，不连接集群
python -m inkblade ui                # 本地控制台 127.0.0.1:8765
python -m inkblade exploit --list    # 武器包与部署前提

有可读集群时用 inkblade pilot --kubeconfig；执行任何模块前都需要先签授权范围。
