InkBlade v0.2.0 preview

Authorized pentesting for Kubernetes ML training and inference clusters. Consent pinning, level gates, a backup gate for write modules and per-action auditing are enforced in code. Without a signed record the CLI and the HTTP API refuse to run.

Preview build: scan, evidence and report paths are usable for pilots. The in-pod collector is moving to the static Rust probe; Python stays the reference until that closes.

Start here

python -m inkblade doctor            # interpreter, write access, port, optional deps
python -m inkblade pilot --dry-run   # offline rehearsal: profile + plan, no cluster contact
python -m inkblade ui                # local console on 127.0.0.1:8765
python -m inkblade exploit --list    # weapon packs and their deployment requirement

To read a cluster you are allowed to test, run inkblade pilot --kubeconfig ~/.kube/config. Running a module needs a signed scope first; inkblade quickstart writes one.

What it covers

286 modules, 29 chains

Recon, lateral movement, network, privilege, code paths, exfiltration, hybrid cloud.

Three evidence layers

Context journal, SQLite audit tables, per-step archive with a SHA-256 manifest.

Bilingual reports

PTES narrative and remediation checklist from one evidence tree.

Vulnerability coverage

41 primitives, 24 components, affected versions; no payloads.

Agent & LLM (optional)

Scanning, exploitation, evidence and reporting are deterministic and need no model. A model can rank candidate modules or run inside L3. Both are off by default; with no endpoint the planner keeps rule order and records the downgrade. L3 needs a signed full-impact RoE, a revocable lead token, an allowlist and four budget caps. Prompts can carry evidence summaries; the page lists what is sent and what stays local. Configuration, data boundary, failure modes.

中文

面向 Kubernetes 训练与推理集群的授权渗透测试。授权范围、技术级别、写操作备份与逐动作审计都在代码里强制执行；没有签署记录时，CLI 与 HTTP API 都拒绝执行。

扫描、利用、证据与报告不需要 LLM。模型只给候选排序或在 L3 循环里工作，默认关闭；没有端点时回到规则排序，并把降级写进提议。

python -m inkblade doctor            # 解释器、写权限、端口
python -m inkblade pilot --dry-run   # 离线演练，不连集群
python -m inkblade ui                # 本地控制台 127.0.0.1:8765

有可读集群时用 inkblade pilot --kubeconfig；跑模块前先签授权。
