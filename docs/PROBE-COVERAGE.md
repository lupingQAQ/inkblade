## 5. Contract

- Every module is a declarative template (`template.json`), executed natively by the Rust probe (`inkblade-probe run-template`/`task`).
- No Python, shell interpreter or module code is dropped into the target Pod.
- `probe-bootstrap` is the only host-executed module and only drops the Rust binary.
- Missing probe / missing target surface fails explicitly; there is no adapter or host fallback.
- Legacy per-family Python tests for `run.py` internals were retired with the execution path; `tests/test_probe_*.py` replace them with two-state template execution and evidence digests.
