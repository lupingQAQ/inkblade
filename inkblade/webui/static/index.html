CONNECT A REAL CLUSTER

三步接入真实集群

控制台只负责会话与可视化；集群导入、授权签署与探针投放由 CLI 完成。以下步骤不会读取本机文件。

  1. 01

    导入 kubeconfig

    选择 kubeconfig 文件或填写路径，作为下一步 CLI 的输入提示。页面不会读取、解析或上传该文件。

    未选择文件

    仅前端提示：不会调用 FileReader，也不会发起文件读取请求。

  2. 02

    签署授权

    打开授权会话并签署 RoE：目标、命名空间、CIDR、级别与时间窗口。未签署时执行路径返回 423。

    inkblade session open --mode kubeconfig --workspace ./work --kubeconfig ~/.kube/config

    授权记录哈希固定在 workspace/consent.json，与每次 run 一同校验。

  3. 03

    启动探针并开始

    将静态 Rust 探针投放到授权 Pod，然后启动 Agent。运行结束后本页自动出现 DAG、时间线、证据与链状态。

    inkblade probe deploy --session <session-id> --via kubectl --binary ./inkblade-probe-linux-amd64
    inkblade agent run --probe <probe-id> --objective read-only-recon --workspace ./work

    无写操作时保持只读；写路径还需要 --allow-write、备份回执与授权级别同时满足。
